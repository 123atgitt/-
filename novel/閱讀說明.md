# 鳴潮主線小說

這是依遊戲「潮汐任務」重寫的小說，從序章寫到第四章第四幕〈夢樞心相由心生〉（約至 3.7）。序章到第四章的每一幕都在裡面：今州、乘霄山、黑海岸、黎那汐塔、拉海洛、夢州。

它要還原的是你在遊戲裡走過的那些時刻：被陌生人握住的手、雨裡的傘、城破前的炮、把權能交出去的那一問、被世界忘掉的人、潮水裡那些死去的臉，以及一隻小狐狸把月燈一盞盞點亮。

幾件先說清楚：

- 敘事用「你」。漂泊者的性別不鎖定，和遊戲裡可選擇的那樣一致。
- 場景、出場順序、關鍵對白盡量貼遊戲演出。敘事補的是場景之間的呼吸，不另編戲。
- 同伴故事只在與主線交會時寫入。純好感支線、活動外傳不展開。
- 幕間若與主線情緒相連，會收進同一章，不另起一份流水帳。
- 這不是官方文本，也不是結局。第四章寫完的時候，路還開著。

**修訂備註：** 初版序章曾誤把傷痕提前寫進雲陵谷，開場也不符遊戲。現已依《萬象新聲·上／下》演出重寫。後續章若發現同樣偏差，會繼續按遊戲流程校正。
